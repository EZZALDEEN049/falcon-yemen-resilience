# إنشاء مستودع GitHub خاص دون أوامر محلية

حساب GitHub المتصل: `EZZALDEEN049`.

1. افتح https://github.com/new بينما أنت مسجّل الدخول إلى الحساب الصحيح.
2. اختر Owner: `EZZALDEEN049`، واكتب الاسم `falcon-yemen-resilience`.
3. حدد **Private**، ثم أنشئ المستودع مع ملف README أولي إن رغبت.
4. في GitHub: افتح المستودع → **Add file → Upload files**. فكّ ضغط ZIP على جهازك، ثم ارفع **محتويات المجلد** مع المجلدات الفرعية، ومنها `.github/workflows/`. لا ترفع ملف ZIP مغلقًا وحده لأن GitHub Actions لن يرى الأكواد الموجودة بداخله.

6. إذا طلب GitHub تفعيل Actions، راجع طلب التفعيل ثم فعّل workflows. افتح **Actions → Full Research Pipeline → Run workflow**.
7. افتح كل Job، ثم قسم Artifacts لتنزيل نتائج العمل. إذا كان الوصول إلى بيانات 2020 غير متاح، تحقق من ملفات manifest وأخطاء المصدر ولا تستخدم نتائج زائفة.
