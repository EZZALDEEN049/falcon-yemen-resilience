Supplement/Reference_And_Event_Original_RIB_12_SHA256.json. Verify SHA-256 and gzip integrity before 
source decoding; the original binaries are not redistributed.



2. Verify locally downloaded source bytes and gzip CRC using Code/fetch_original_2020_ribs.py (event 
manifest) and/or the original repository parser source; source checks must fail closed on hash mismatches. The 
event and reference six-RIB collections are separate datasets with different snapshot windows and counts.

3. BOTH SOURCE-NATIVE ENDPOINT PAIRS COMPLETED: original RIB files were processed into peer–prefix 
CSVs in Evidence/BGP_2020/{rrc00,rrc01,rrc10}/ for the event and 
Evidence/Reference_2020_20200102/{rrc00,rrc01,rrc10}/ for the one-week-earlier reference. Raw event export is 
pinned at 907b59027807ab292d33886d36e65e2bb07f63c6; reference export at 
e7d0f51729ef8fffe138fa7fc34a3130455e1ad2. Verify each individual audit.json and reproduce group/fixed-key 
analyses using the included scripts. These two-snapshot analyses are separate from the historical RRC00 
UPDATE replay.

4. From the extracted archive root, run Code/verify_reviewer_bundle.py for source-export numerical and 
SHA-256 checks, then run Code/compare_2020_event_vs_non_event.py --event-root Evidence/BGP_2020 --
reference-root Evidence/Reference_2020_20200102 --output-dir QA/REPRODUCED_REFERENCE_LOCAL. 
These verify the released observation-level exports and their aggregate calculations; they do NOT substitute for 
downloading and decoding the original 12 RIPE MRT compressed RIB binaries.

5. IODA 2020 ORIGINAL-IMAGE GATE CLOSED: obtain the original-size PNG bytes from the two direct 
publisher URLs above (no resizing), verify source hashes, and run Code/recheck_ioda2020_original_pngs.py
